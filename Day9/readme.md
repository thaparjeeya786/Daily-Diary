## Key Concepts
- **Mean (Average):** Sum of values ÷ number of values. Example: (10+20+30)/3 = 20.  
- **Median (Middle Value):** Middle value in an ordered list. Example: 5,10,15 → Median = 10.  
- **Mode (Most Frequent):** Value occurring most often. Example: 1,2,2,3 → Mode = 2.  
- **Standard Deviation:** Measures how spread out values are from the mean.  
- **Percentiles:** Shows relative rank. Example: 75th percentile = scored better than 75% of others.  
- **Scatter Plot:** Graph with dots showing relationships between two variables (e.g., study time vs. exam score).
