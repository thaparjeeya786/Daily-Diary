## Vim and Workflow
**Vim** is a lightweight, command-line text editor used by developers and system administrators.  
- **Modes:**  
  - *Normal Mode* – navigation and commands  
  - *Insert Mode* – typing text (`i` to enter, `Esc` to exit)  

**Basic Commands:**  
- `:w` → save file  
- `:q` → quit  
- `:wq` → save and quit  
- `:q!` → quit without saving  

## Kaggle
