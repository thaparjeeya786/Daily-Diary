## Key Concepts
- **KNN (K-Nearest Neighbor):** A supervised ML algorithm that classifies data by comparing it to its nearest neighbors. Example: Classifying fruit as apple or orange based on size and color.  
- **CNN (Convolutional Neural Network):** A deep learning model for image processing. Uses convolution layers, pooling, and fully connected layers to detect patterns. Example: Face detection, handwriting recognition.  
- **LAMP Stack:**  
  - **Linux** – Operating system.  
  - **Apache** – Web server.  
  - **MySQL** – Database.  
  - **PHP** – Scripting language for dynamic web pages.  
  - **Working:** Browser request → Apache → PHP (with MySQL if needed) → Response back to browser.
