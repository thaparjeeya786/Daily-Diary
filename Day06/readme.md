## Introduction to Jupyter Notebook
Jupyter Notebook is a browser-based interactive environment where users can:
- Write and execute code  
- Add markdown notes and headers  
- Display visualizations and outputs  
- Combine code + explanation for better understanding
It is ideal for learners, data analysts, and developers due to its flexibility and simplicity.
