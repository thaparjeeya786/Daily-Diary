## What is GitHub?
GitHub is a cloud-based platform that uses Git, a version control tool, to help developers collaborate, track changes, and manage their code.  
GitHub allows users to:
- Store and share projects  
- Create repositories (repos)  
- Review and manage versions of code  
- Collaborate with others on open-source or private projects  

## Basic Git/GitHub Commands

| Command | Description |
|--------|-------------|
| `git config --global user.name "Your Name"` | Set global Git username |
| `git config --global user.email "you@example.com"` | Set global Git email |
| `mkdir store` | Create a new directory |
| `cd store` | Enter the directory |
| `git init` | Initialize a Git repository |
| `git status` | Check file changes/status |
| `git add filename.txt` | Stage a specific file |
| `git add *.txt` | Stage all `.txt` files |
| `git remote add <address>` | Add remote GitHub repo |
| `git remove rm` | Remove a remote from local repo |
| `git clone <repo-url>` | Clone an existing repo |
| `git branch` | View all branches |
| `git merge branchname` | Merge another branch with the current one |
| `git fetch` | Get updates from the remote repo |
| `ls` | List files in current directory |

 Git commands are case-sensitive and require correct syntax to function properly.
