## Linear Regression
Linear regression is a supervised ML algorithm that learns from labeled datasets and fits the most optimized linear function for prediction.  

- **Independent Variable (X):** Input feature (e.g., hours studied).  
- **Dependent Variable (Y):** Output/target (e.g., exam score).  

### Equation of Linear Regression
\[
y = mx + b
\]
Where:  
- *y* → predicted value  
- *x* → input feature  
- *m* → slope of the line  
- *b* → intercept (where the line crosses Y-axis)  

## Best Fit Line
The main goal is to find a straight line that minimizes the error between actual values and predicted values. This line, called the line of best fit, helps in making predictions for unseen data.
Example: Predicting exam scores based on study hours. As study hours increase, exam scores rise in a linear fashion.

## Loss Function & Gradient Descent
- Loss Function: Measures the error between predicted values and actual values.  
- Gradient Descent: Optimization technique used to adjust *m* and *b* gradually to minimize the loss, making the line fit the data better over time.
