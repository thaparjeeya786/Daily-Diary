## Introduction to Linux
Linux is a powerful, open-source operating system known for its speed, security, and stability.  
Unlike Windows or macOS, it’s free and highly customizable, making it a popular choice among developers, sysadmins, and programmers.
Linux often relies on the command-line terminal instead of graphical interfaces. This allows for more control and efficiency, especially once users are familiar with the commands.

## Common Linux Commands

| Command  | Description                                 |
|----------|---------------------------------------------|
| `ls`     | List the directory contents                 |
| `cd`     | Change directory                            |
| `cd ..`  | Move one level up in the directory          |
| `cp`     | Copy files to another folder                |
| `mv`     | Move files to another folder                |
| `mkdir`  | Create a new directory                      |
| `rmdir`  | Remove a directory                          |
| `clear`  | Clear the terminal window                   |
| `exit`   | Close the terminal                          |
| `pwd`    | Show present working directory              |
| `touch`  | Create a new file                           |

Note: Linux commands are case-sensitive.
