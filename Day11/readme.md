## Confusion Matrix
A confusion matrix is a table used to evaluate classification models by comparing actual vs predicted outcomes.  

- **True Positive (TP):** Model correctly predicts positive.  
- **True Negative (TN):** Model correctly predicts negative.  
- **False Positive (FP):** Model predicts positive when it’s actually negative (*Type I Error*).  
- **False Negative (FN):** Model predicts negative when it’s actually positive (*Type II Error*).  

From the confusion matrix, we can derive important metrics:  
- **Accuracy** – Overall correctness of the model.  
- **Precision** – How many predicted positives were correct.  
- **Recall** – How many actual positives were detected.  
- **F1-Score** – Balance between precision and recall.  

## Large Language Models (LLMs)
LLMs are neural network-based AI models trained on massive datasets to process and generate human-like text.  
They use self-supervised learning to perform tasks such as:  
- Text generation  
- Translation  
- Summarization  
- Conversational AI (Chatbots)  
- Code generation  

Examples of LLMs:  
- ChatGPT (by OpenAI)  
- BERT (by Google)  

### GPT Models
- **GPT-1 (2018):** 117M parameters  
- **GPT-2 (2019):** 1.5B parameters  
- **GPT-3 (2020):** 175B parameters (basis of ChatGPT)  
- **GPT-4 (2023):** Trillions of parameters  
- **GPT-4 Turbo (2023):** Optimized for speed & cost  

## AI vs ML
| Aspect       | Artificial Intelligence (AI)                | Machine Learning (ML)                  |
|--------------|---------------------------------------------|----------------------------------------|
| **Definition** | Simulating human intelligence in machines  | Training machines to learn from data    |
| **Goal**      | Make machines think and act intelligently   | Enable systems to improve with experience |
| **Approach**  | Broad (reasoning, learning, planning, etc.) | Focused on algorithms & data-driven learning |
