## What is TensorFlow?
TensorFlow is a machine learning and deep learning framework developed by Google Brain. It simplifies the process of building, training, and deploying models across different platforms. It supports tasks ranging from natural language processing (NLP) to image recognition and reinforcement learning.  

## Features of TensorFlow
- **Scalability** – Works on small to very large systems.  
- **Comprehensive ecosystem** – Includes TensorFlow Lite, TensorFlow Serving, and Model Optimization.  
- **Automatic Differentiation (Autograd)** – Enables backpropagation.  
- **Multi-language support** – Python, C++, Java, and more.  
- **Cross-platform deployment** – Cloud, mobile, and edge devices.  

## Working of TensorFlow
1. **Train a Model** – Build and train the model on a dataset.  
2. **Convert the Model** – Prepare it for deployment.  
3. **Optimize the Model** – Reduce model size and improve speed.  
4. **Deploy the Model** – Use on servers, cloud, or edge devices.  
5. **Inference** – Use the trained model for predictions.
